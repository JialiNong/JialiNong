## 🧳 旅行 AI skills

像老练的穷游玩家一样规划欧洲旅行的 agent skill，Claude、Cursor、Codex、ChatGPT、Gemini 都能用。agent 只负责输出 JSON，再由固定模板渲染成一个中英双语页面。

🚆 [**europe-route-finder-skill**](https://github.com/JialiNong/europe-route-finder-skill) - 把出发地和目的地两端都扩展成枢纽城市，找出订票网站搜不到的火车、大巴和夜车路线，再对比运营商官网和比价平台的真实票价

🏡 [**europe-town-stay-finder-skill**](https://github.com/JialiNong/europe-town-stay-finder-skill) - 在小镇和公共交通 1 小时内能到的所有村镇里找住宿，对比 Booking 和 Airbnb，顺便整理周边的户外运动和 komoot 徒步路线

🎨 [**europe-city-culture-planner-skill**](https://github.com/JialiNong/europe-city-culture-planner-skill) - 从城市官方旅游网站出发排文艺向行程：当期展览、菜市场、观景点、轮渡和电车、免费徒步导览、演唱会和脱口秀
